XrayC 独立 UI 预览

在 frontend 目录执行 npm run preview:ui，然后打开 http://127.0.0.1:5173/admin/login。
示例账号：admin；密码：local-preview（仅本机示例服务，不是真实鉴权服务）。
示例服务仅监听 127.0.0.1:18880；前端预览仅监听 127.0.0.1:5173。
VITE_UI_PREVIEW=true 时 API 强制指向这个本机示例服务，不读取正式站数据。
预览包含用户、节点、入口、出口、分组与套餐示例。新建线路和订阅/规则保存仅保存在内存，重启预览即重置。
其他未模拟的写操作会明确返回提示。不能用此预览结果代替正式业务验收。
退出时按 Ctrl+C，两个预览进程一并停止；遇到端口冲突不会终止已有进程。
普通 npm run build 不设置 VITE_UI_PREVIEW，仍是正常的生产前端构建。
