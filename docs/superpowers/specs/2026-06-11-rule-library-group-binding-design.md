# 规则库与分组绑定设计

## 目标

订阅规则改为可复用的规则库模型。管理员先创建多套规则，再到分组里选择要绑定的规则。规则库被多个分组绑定后，修改规则库会同步影响所有绑定分组。

本设计替代旧的 `line_groups.dedicated_rules` 直写模式。旧模式只能在单个分组里直接维护规则，容易造成重复、遗漏和前后端理解不一致。

## 数据模型

新增规则库表 `subscription_rule_sets`：

- `id`：规则库 ID。
- `name`：规则库名称，例如 AI 规则、游戏规则、国内直连规则。
- `description`：备注。
- `enabled`：是否启用。
- `rules`：规则内容，仍保存为有序字符串数组，兼容现有 Clash/mihomo 规则编辑器。
- `created_at`、`updated_at`：审计时间。

新增分组绑定表 `line_group_rule_set_bindings`：

- `line_group_id`：分组 ID。
- `rule_set_id`：规则库 ID。
- `position`：绑定顺序。
- `enabled`：该分组下是否启用这套规则。

一个分组可以绑定多套规则，一套规则可以被多个分组绑定。绑定顺序决定订阅里规则的输出顺序。

旧字段 `line_groups.dedicated_rules` 进入兼容迁移状态：迁移时把旧规则自动生成一套规则库，例如 `分组名-历史规则`，并绑定回原分组。订阅生成代码优先读取新绑定关系；迁移完成后不再从前端写入旧字段。

## 订阅生成

套餐仍然授权分组。用户拉取订阅时，系统按套餐授权分组生成代理分组，并为每个代理分组加载绑定的规则库。

生成顺序：

1. 遍历订阅中可见的分组。
2. 读取该分组绑定且启用的规则库，按绑定顺序展开。
3. 每条规则按当前分组重写目标：
   - `PROXY` 或未写动作的规则，输出时改为当前分组名称。
   - `DIRECT` 保持直连。
   - `REJECT`、`REJECT-DROP`、`PASS` 保持原动作。
4. 所有分组绑定规则输出完成后，再输出通用规则。
5. 通用规则没有命中时，最后 `MATCH` 默认走套餐默认分组；如果没有设置套餐默认分组，则走订阅内第一个可用分组。

同一套规则库绑定到多个分组时，订阅中会按每个分组各自生成一份目标不同的规则。例如 AI 规则绑定到 `AI 高速` 和 `AI 备用`，两组都会输出 AI 域名规则，但目标分别指向自己的代理分组。

## 管理后台

新增或改造规则管理入口为“规则库”：

- 列表展示规则库名称、启用状态、规则数量、备注、更新时间。
- 支持新增、编辑、停用、删除规则库。
- 规则编辑复用现有 `RuleEditor`，继续支持可视化添加规则和高级文本批量编辑。
- 删除规则库前需要检查绑定关系；已被分组绑定时默认禁止删除，管理员应先解除绑定。

分组编辑页增加“绑定规则”区域：

- 选择一套或多套规则库。
- 支持调整绑定顺序。
- 支持在该分组下临时启用或停用某套绑定。
- 不再直接编辑原始规则内容。

订阅通用规则仍保留，但只负责全局兜底和全局直连/拒绝规则，不承担具体分组的规则内容维护。

## API

新增后台规则库接口：

- `GET /api/admin/subscription-rule-sets`
- `POST /api/admin/subscription-rule-sets`
- `PUT /api/admin/subscription-rule-sets/{id}`
- `DELETE /api/admin/subscription-rule-sets/{id}`

分组接口新增绑定字段：

- 读取分组时返回 `rule_set_bindings`。
- 创建和更新分组时接受 `rule_set_bindings`，后端校验规则库存在、顺序合法、无重复绑定。

旧的 `dedicated_rules` 字段保留只读兼容期，避免历史接口或测试数据直接崩溃；新前端不再提交该字段。

## 错误处理

- 规则库名称不能为空。
- 单套规则库内空规则会被清理。
- 分组绑定不存在的规则库时返回 400。
- 同一分组重复绑定同一规则库时返回 400。
- 删除已绑定规则库时返回 409，并提示先解绑。
- 订阅生成时遇到已停用规则库或停用绑定，直接跳过。

## 测试

后端测试：

- 规则库 CRUD。
- 分组绑定多套规则库。
- 同一规则库绑定多个分组后，订阅分别重写到各自分组。
- 修改规则库后，所有绑定分组订阅同步生效。
- 删除已绑定规则库返回冲突。
- 旧 `dedicated_rules` 迁移成规则库并绑定回原分组。

前端测试：

- 规则库页面可新增、编辑、停用规则。
- 分组可以绑定多套规则库并排序。
- 分组不再显示旧的直接编辑规则内容入口。

真实订阅测试：

- 创建两套规则库并绑定到两个分组。
- 套餐授权两个分组。
- 用户拉取订阅后应看到两个代理分组。
- 每个代理分组的绑定规则目标都指向对应分组。
- 未命中规则最终走代理兜底。
