# 订阅生命周期

用户注册或兑换套餐后生成用户级订阅 Token。订阅下载时中心按套餐授权分组展开分组内入口出口绑定节点，再查找这些绑定节点对应的、已启用、已同步且可连接的中转入口，并结合出口可用状态和用户剩余额度生成 Clash/mihomo YAML。一个入口绑定多个出口时，订阅按绑定节点输出多个代理项；这些代理项可以使用同一个中转入口端口，但节点名、用户凭据和后台路由归属必须按绑定节点区分。

订阅下载成功会记录来源 IP 观察事件，管理员后台可在用户管理的设备管理抽屉中与节点使用 IP 合并查看；该事件不参与订阅鉴权、路由、计费、限速或套餐授权，也不向普通用户接口回显。

订阅只包含中转入口地址、入口协议、客户端网络模式和用户凭证，不包含第三方出口 host、账号密码、UUID、公钥或代理 URL。订阅设置只控制 YAML 基础字段、线路过滤和可选自动测速组，不再自定义普通代理分组；普通 `select proxy-groups` 由套餐授权分组自动生成，组内代理项来自该分组内绑定节点对应的中转入口。后台规则设置页集中维护通用规则和可复用规则库；分组绑定一套或多套规则库，绑定规则生成时位于通用规则之前，“走绑定分组”指向当前分组，直连和拒绝保持原动作；套餐配置默认出口分组，最终 `MATCH` 指向该分组，未匹配到任何规则时默认走代理。

access-agent 下发配置时，同入口多绑定（含限速用户）可以合并为一个实际 runtime inbound（守真实端口）；限速用户靠每用户 fwmark + 带 mark 出站区分，每个绑定节点仍写入独立用户凭据和 `xrayc-line-<access_line_id>--<xray_user_key>` 统计 email，确保 session、账本和出口 routing 仍归属具体绑定节点。

订阅 token 是运行时授权边界。token 被撤销、过期或不存在时，订阅下载必须失败，access-agent 心跳返回的授权用户和 Xray 入站配置也必须同步移除该用户凭据，避免旧客户端在无法拉取订阅后仍然继续跑通流量。

当过滤后没有任何可授权用户或可用入口时，中心仍必须生成稳定的空配置版本。agent 如果上报的 `applied_config_version` 还是旧版本，心跳必须返回 `config_status.required=true` 且 `config=null`，由 agent 写入空 Xray 配置并重载，清除节点上残留的旧入站用户。
