# 系统总览

XrayC V2 由中心控制面、PostgreSQL、前端、access-agent 和 Xray 组成；接入节点运行 `xray-core` + `access-agent`（单内核 Xray），所有入口都由 Xray 处理。中心负责用户、套餐、分组、出口管理、入口管理、中转节点、计费、配置下发和数据库自动备份；access-agent 部署在接入节点，主动回连中心并应用 Xray 配置。

产品主路径是出口管理保存所有来源的出口线路，入口管理把中转入口和出口线路组成绑定节点，分组只有一层并直接归类绑定节点，套餐直接授权分组并设置倍率。客户端连接订阅中的中转入口。第三方出口、普通自建上游和中转节点本机出口服务先进入统一出口管理，再由入口管理绑定为订阅节点，不直接暴露真实出口给用户。本机出口服务可批量创建多协议出口线路并进入出口管理；控制和计费仍由中转节点/access-agent 上报和中心账本处理。

当前方案、部署和运营闭环的完整公开口径见 `文档/架构/当前方案与运营闭环.md`。
