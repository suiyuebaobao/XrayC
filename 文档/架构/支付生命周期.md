# 支付生命周期

支付功能当前暂停，第一版订阅开通优先通过兑换码或后台操作闭环。订单查询、订单表、支付记录表和支付回调接口保留为后续启用占位；默认 `XRAYC_PAYMENT_ENABLED=false` 时，订单创建和支付回调写接口稳定返回 HTTP 503、`code=payment_disabled`，不创建订单、不校验回调签名、不写支付记录。

后续启用真实支付后，用户创建订单并等待支付回调。中心校验回调签名和 `tx_id` 幂等，成功后把订单置为 `paid`，写入 `payment_records`，并开通或续费订阅。

重复回调不得重复增加套餐权益。付费套餐重复购买或兑换码续费沿用当前单一订阅模型：从 `max(existing_expires_at, now)` 延长有效期，叠加套餐流量，不清零已用流量。基础套餐到期由 Worker 按基础套餐 `duration_days` 自动重置为新的基础周期，默认是 30 天月度口径；付费套餐到期后自动切换回基础套餐。异常订单修复必须保留审计信息，并核对用户订阅期限和套餐额度。
