# 生产部署

## 服务

生产部署使用 Docker Compose 启动 PostgreSQL、API、Worker 和 Caddy。所有服务应配置 restart 策略和健康检查；前端静态资源由 Caddy 镜像在构建阶段生成并托管。

Worker 与 API 必须使用同一迁移目录。Worker 除基础套餐周期重置、付费套餐到期回基础、订单过期、认证临时状态清理和运行态保留外，还会按探测策略生成 queued 组合出口探测任务，并按后台 `database_backup` 策略执行 PostgreSQL 自动备份；queued 任务租约反复过期达到投递上限后会转为 `timeout`，并按失败探测推进组合状态和用户出口重算。生产监控需要同时观察 Worker 日志、`access_exit_probes` queued/timeout 积压、access-agent 心跳领取情况、`database_backup_state` 和备份目录文件增长情况。

## 必要环境变量

- `DATABASE_URL`
- `XRAYC_ENV=production`
- `JWT_SECRET`
- `JWT_EXPIRES_IN=30m`
- `JWT_REFRESH_EXPIRES_IN=7d`
- `XRAYC_REFRESH_COOKIE_SECURE=true`
- `DEPLOY_ARTIFACT_TOKEN`
- `SEED_DEMO_DATA=false`
- `DATABASE_BACKUP_DIR=/backups`

支付功能当前暂停，默认保持 `XRAYC_PAYMENT_ENABLED=false`。此状态下 `POST /api/orders` 和 `POST /api/payment/callback` 保留路由但稳定返回 503、`code=payment_disabled`，不创建订单、不校验回调签名、不写支付记录。后续启用真实支付时，再额外配置 `XRAYC_PAYMENT_ENABLED=true`、高强度 `PAYMENT_CALLBACK_SECRET`、`PAYMENT_MIN_CONFIRMATIONS` 和非占位 `PAYMENT_RECEIVE_ADDRESS`。

密钥只允许通过私有环境变量、私有密钥文件或密钥系统注入。
生产模式会校验 `DATABASE_URL`、`JWT_SECRET`、`JWT_EXPIRES_IN`、`JWT_REFRESH_EXPIRES_IN` 和 `SEED_DEMO_DATA=false`，缺失、格式错误、弱配置、开发占位值或过长 JWT 生命周期都会启动失败；只有 `XRAYC_PAYMENT_ENABLED=true` 时才校验支付回调密钥和收款地址。生产环境默认给 Refresh Cookie 追加 `Secure` 属性，且不允许设置为 `false`。
Caddy 反代必须让后端只信任受控连接来源，不得把客户端自带的转发链追加为可信客户端来源，否则会污染审计来源和 IP 频控维度。

生产 Compose 必须给 Worker 挂载持久化且可写的 `DATABASE_BACKUP_DIR`，默认 `/backups`。官方运行镜像内置 PostgreSQL 16 版 `pg_dump/pg_restore`；自定义镜像必须提供与 PostgreSQL 主版本兼容的 client 工具。上线后至少检查一次 `site_settings.database_backup_state`、备份目录中的 `xrayc-postgres-*.dump` 文件和 Worker 日志，确认自动备份没有因目录权限、磁盘空间或 client 版本失败。

生产录入或导入 VLESS 线路协议档时，必须按 `security` 区分校验：`security=reality` 才要求 Reality public key、short id、fingerprint 等字段；`security=tls` 只校验 TLS/SNI/ALPN 等 TLS 字段，不要求 Reality public key 或 short id。Trojan 用户入站必须启用 TLS；任何中转入口或上游协议档声明 `security=tls`、SNI 或证书字段时，部署流程必须主动准备或验证证书链、私钥文件权限、SNI/域名匹配和 Xray 配置预检。真实测试使用私有清单域名，公开日志、部署摘要和测试报告只能写“私有清单域名”，不得记录真实域名、真实上游地址、UUID、public key 或完整代理 URL。

生产节点的 SSL 自动申请必须在 Agent 安装脚本中同时提供证书域名和 ACME 邮箱；任一缺失不得尝试申请证书。上线后由 access-agent 心跳持续上报证书摘要，管理平台只展示状态和有效期，并通过单节点续期任务触发本机 certbot 非强制续期，禁止跨节点续期或回传证书敏感内容。

涉及运行数据验收时，除 Playwright smoke 外，还必须运行 `STRICT_AGENT_TRAFFIC=1 bash scripts/real-smoke.sh` 并提供私有 `AGENT_TOKEN`、`ACCESS_NODE_ID` 和 `ACCESS_LINE_ID`，确保 agent traffic 上报返回 2xx。

真实发布前运行 `make check-real-release-env`，确认 `.env.real-release` 或 `XRAYC_REAL_RELEASE_ENV_FILE` 指向的私有 env 已包含真实 Playwright no-mock 账号、真实订阅、真实接入节点、Agent 安装清单、真实客户端代理变量和第三方出口矩阵变量。启用长稳、压测、认证 HA 或误操作恢复 UAT 时，只在私有 env 中设置对应 `RUN_*` 开关，公开发布记录只写阶段结果。
