# 订单接口

## 用户接口

- `GET /api/orders`
- `POST /api/orders`

支付功能当前暂停。`GET /api/orders` 保留用于查看历史订单；`POST /api/orders` 作为后续支付接口占位，`XRAYC_PAYMENT_ENABLED=false` 时稳定返回 HTTP 503、`{"success":false,"code":"payment_disabled"}`，不创建新订单。`XRAYC_PAYMENT_ENABLED=true` 时保持现有订单创建流程。

支付重新启用后，订单支付成功必须沿用当前单一订阅续费语义：从 `max(existing_expires_at, now)` 延长有效期，叠加套餐流量额度，保留已用流量，并按新套餐授权分组标记相关中转节点待同步。重复支付回调必须幂等，不得重复叠加有效期或流量。

## 管理接口

- `GET /api/admin/orders`

## 支付回调

- `POST /api/payment/callback`

支付回调为可选支付能力，当前默认暂停。`XRAYC_PAYMENT_ENABLED=false` 时稳定返回 HTTP 503、`{"success":false,"code":"payment_disabled"}`，不校验签名、不写入订单状态。后续设置 `XRAYC_PAYMENT_ENABLED=true` 启用真实支付后，回调必须校验签名并按 `tx_id` 幂等，签名错误不改变订单状态。
