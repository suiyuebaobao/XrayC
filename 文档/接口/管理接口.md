# 管理接口

## 访问规则

`/api/admin/*` 必须使用管理员 JWT。匿名访问返回 401，普通用户访问返回 403。

## 主要模块

- 用户、订单、兑换码、邀请码、认证安全和订阅设置。
- 销售首页配置，供公网 `/` 页面渲染销售文案、卖点、场景和 FAQ。
- 出口管理、中转节点、中转入口、扁平分组和套餐授权范围。
- 出口管理和分组维护；出口资源、出口协议档在后台包装为出口管理对象，支持完整增删改查、搜索、编辑、探测和删除，管理员可查看真实配置。套餐直接授权分组，不维护多级结构或组合成员。
- 运营中心、运行数据、探测策略和手动探测。
- 管理员审计日志只读查询。
- 字段加密状态和密钥轮换 dry-run/执行。

## 审计日志

- `GET /api/admin/audit-logs`：管理员分页查询审计日志，查询参数 `page` 默认 `1`，`page_size` 默认 `50`、最大 `200`。
- 响应只返回审计 ID、时间、操作者邮箱、动作、资源类型、资源 ID、结果和脱敏摘要，并兼容 `items` 与 `audit_logs` 两个列表字段。
- 响应不得返回 `client_ip`、密码、Token、订阅链接、第三方完整代理配置、出口协议档敏感配置或完整部署凭据；该限制针对审计日志，不影响出口管理后台编辑页读取真实出口配置。

## 字段加密

- `GET /api/admin/field-encryption/status`：查看字段加密状态，只返回是否配置、主 `kid`、key 数量、site settings、内部 exit endpoints、内部 access lines 扫描数量、已加密字段、旧 `kid` 字段、明文敏感字段计数和最近一次轮换任务摘要。
- `POST /api/admin/field-encryption/rotate`：执行字段密钥轮换，Body 为 `{"dry_run": true}` 时只计算将要重写的 `site_settings.auth_security`、`exit_endpoints` 和 `access_lines.inbound_config` 数量；`{"dry_run": false}` 会把旧 `kid` 密文和兼容明文敏感字段重加密为当前主 `kid`。
- 每次 dry-run 或正式轮换都会写入 `field_encryption_rotation_jobs`，响应返回 `job_id`、状态和计数；执行阶段使用 PostgreSQL advisory lock，已有轮换执行中时新任务会失败并记录失败摘要；正式重写会对目标行加 `FOR UPDATE` 行锁，超过 2 小时未完成的 running 任务会自动标记为 failed。
- 成功和失败都会写入管理员审计；失败审计只记录错误类别和脱敏标记。
- 响应、任务记录和审计只允许包含计数、`primary_kid`、`dry_run`、状态、错误类别和重写数量，不得返回明文、密文、key material、SMTP 密码或出口协议档敏感内容。

## 用户订阅

- `GET /api/admin/users`：管理员查看用户列表，聚合邮箱账号、角色、启用状态、套餐、订阅状态和流量摘要。
- `POST /api/admin/users`：管理员主动新增用户，Body 包含 `email`、`password`、可选 `disabled`、`is_admin`、`plan_id`；不走公开注册的邀请码、验证码和邮箱验证码流程。服务端会生成用户级 `xray_user_key`、订阅 Token 和默认/指定套餐订阅；响应不得回显明文密码。
- `PATCH /api/admin/users/{id}`：管理员修改用户邮箱、启用/禁用状态、管理员标识和当前套餐。邮箱修改不改变 `xray_user_key`；禁用、启用或切换套餐会标记接入节点配置待同步；切换套餐会按新套餐授权分组重算用户入口授权和出口映射。
- `DELETE /api/admin/users/{id}`：管理员删除用户。服务端会阻止删除当前登录管理员和最后一个启用管理员；删除会清理该用户订阅、令牌、分配、认证会话、订单、账本和运行快照，并标记接入节点配置待同步。
- `POST /api/admin/users/batch-delete`：管理员批量删除用户，Body 为 `{"user_ids":["<uuid>"]}`。服务端会先去重并阻止删除当前登录管理员；数据库删除在单事务内完成，任一用户不存在或触发管理员保护时整批回滚，不产生半删状态。
- `GET /api/admin/users/{id}/subscription`：管理员查看指定用户订阅，允许在管理员界面展示完整订阅链接，便于客服协助，但不得写入公开日志、截图、日报或测试报告。
- `GET /api/admin/users/{id}/traffic-logs`：管理员在后台“流量日志”页或用户管理快捷入口查看指定用户的详细流量日志。查询参数支持 `page`、`page_size`、`from`、`to`、`access_line_id` 和 `exit_endpoint_id`；响应只返回该 `user_id` 仍在详细日志保留期内的账本记录、访问 IP、IP 哈希、入口、接入节点、出口端点、真实流量和扣费流量。超过保留期的明细会先汇总到 `usage_daily_rollups` 和 `usage_hourly_rollups` 后删除，只用于运营排行和健康检查历史统计，不再能按单条明细回放。明文访问 IP 只允许在管理员后台用户级日志中展示，普通用户接口、订阅、公开日志、截图和测试报告不得回显。
- `GET /api/admin/users/{id}/devices`：管理员在用户管理页查看该用户的 IP 观察列表。查询参数支持 `page` 和 `page_size`；响应合并成功订阅拉取来源和节点使用来源，同一明文 IP 只展示一条，并返回首次出现、最近出现、来源、次数、最近入口、最近中转节点和最近会话状态。该接口只服务管理员排障和风控观察，不参与鉴权、限速、扣费、订阅输出或线路选择。
- `POST /api/admin/users/{id}/subscription-token/reset`：管理员重置指定用户订阅链接，响应返回新链接，旧 `/sub/{token}` 立即失效；服务端同时轮换节点入站凭据和统计归属 key，清理旧会话/快照并标记中转节点配置待同步。
- `POST /api/admin/users/{id}/reset-password`：管理员直接为目标用户设新密码，Body 为 `{"new_password":"<plaintext>"}`。管理员 JWT 鉴权通过即直接复用统一改密逻辑——**与用户自助改密不同，无需任何邮箱验证码（管理员本身即授权）**。服务端在同一事务内做密码强度校验（最少 8 位，弱密码 400）、Argon2 重哈希并撤销该用户全部刷新令牌（强制各设备用新密码重登）；写审计日志 `user.reset_password`（actor=管理员、resource=目标用户、`password_redacted=true`、`sessions_revoked=true`），绝不记明文新密码。用户不存在返回 404，用户已禁用返回相应错误。响应不回显明文密码。
- 后台编辑套餐流量额度后，绑定该套餐的现有订阅额度会同步更新，后台用户订阅页和订阅客户端的 `Subscription-Userinfo` 应立即显示新总量；已用流量不重置。

## 邀请码管理

- `GET /api/admin/invite-codes`：管理员查看全部邀请码，返回邀请码、邀请人邮箱快照、使用状态、使用人邮箱快照、使用时间和创建时间。
- `POST /api/admin/invite-codes`：管理员批量生成邀请码，Body 为 `{"count": 1}`，单次最多 100 个；管理员生成不受用户自助生成开关和额度限制。
- `DELETE /api/admin/invite-codes/{code}`：管理员删除未使用邀请码。已使用邀请码不能删除，必须保留邀请来源追责记录。

## 手动探测

兼容路径包括 `POST /api/admin/exit-endpoints/{id}/probe` 和 `POST /api/admin/access-operations/probe`。

`GET/PUT /api/admin/access-operations/settings` 维护运营策略。`probe_policy` 字段包括 `exit_auto_failover_enabled`、`exit_failure_threshold`、`exit_recovery_threshold`、`exit_window_minutes`、`exit_probe_interval_seconds`、`probe_queue_batch_size` 和 `max_pending_probe_tasks`。Worker 按该策略定时写入 `access_exit_probes.status=queued`，access-agent 心跳领取 `probe_tasks` 后回报非 queued 结果；queued 记录只表示待执行任务，不参与失败/恢复阈值。`traffic_log_retention` 字段维护详细流量日志保留策略：`detail_retention_days` 默认 14，范围 1-3650；`prune_enabled` 默认 true；`delete_batch_size` 默认 5000，范围 100-100000。启用清理时，Worker 会把过期 `usage_ledgers` 明细汇总到 `usage_daily_rollups` 和 `usage_hourly_rollups` 后再删除明细，不二次修改用户已用流量。`database_backup` 字段维护 PostgreSQL 自动备份策略：`enabled` 默认 true，`interval_days` 默认 1 且范围 1-30，`retention_days` 默认 30 且范围 1-3650；Worker 到期后使用 `pg_dump --format=custom` 写入服务器备份目录，并按保留天数清理旧备份。

手动探测只登记 queued 任务；下一次 access-agent 心跳领取后优先按任务携带的脱敏 target 执行协议感知探测，target 缺失时才回退当前 `AccessConfig`。HY2/Hysteria2 中转入口和出口 endpoint 使用 UDP 可达性探测，本机 UDP 端口明确拒绝时必须记为 `unhealthy`，不能按 TCP connect、`unknown` 或仅 UDP send 判定通过。

## 中转节点部署

- `POST /api/admin/access-nodes`：在平台新增中转节点。手动安装路径由管理员填写名称、节点地址、端口、节点鉴权码和备注；一键安装路径由平台解析脚本输出的节点鉴权码并自动调用同一创建逻辑。服务端只保存 token 哈希。
- `POST /api/admin/access-nodes/one-click-install`：可选一键安装 Agent。请求包含节点信息、SSH 连接信息、部署选项、可选证书域名和 ACME 邮箱；SSH 密码和私钥只在本次请求内使用，不写入数据库、审计、部署任务或日志。安装成功后平台自动创建中转节点。
- `POST /api/admin/access-nodes/install-guide`：生成中转节点 Agent 手动安装说明。请求只包含控制面地址、安装目录、Compose 项目名、Xray API 端口、可选期望入口端口、可选证书域名和 ACME 邮箱；该接口只返回服务器本地执行材料。
- 重装已有节点时可传 `access_node_id` 生成带节点上下文的说明；新增节点可走一键安装自动创建，也可走手动安装说明后用节点鉴权码绑定。
- 安装选项支持 `control_plane_url`/`panel_url`、`deploy_artifact_token`、`install_dir`、`compose_project`/`compose_project_name`、`xray_api_server`、`xray_api_listen_host`、`xray_api_listen_port`/`xray_api_port`、`heartbeat_interval_seconds`、`traffic_interval_seconds`、`session_idle_seconds`、`expected_listen_ports`、`disable_legacy_systemd_units` 和 `force_reinstall`。
- 中转节点需要提供本机出口能力时，使用 `POST /api/admin/access-nodes/{id}/local-exit-lines` 批量添加该服务器自建出口线路。前端默认展示 VLESS、HY2、Shadowsocks、Trojan 四类协议行，每条线路选择网络模式、端口和必要字段并自动生成连接配置；服务地址默认读取所属中转节点地址，管理员只在默认值不符合实际监听地址时覆盖。接口只写入统一出口管理，不自动创建用户入口，也不会加入分组。
- `expected_listen_ports` 省略或为空时不做端口 readiness 断言；订阅入口端口恒为逻辑中转入口端口、不因用户级限速变化（限速靠每用户 mark 区分），端口监听时序由节点实际收敛决定，默认不用逻辑中转入口端口判断安装成功。显式传入时必须是 1-65535 的端口数组。
- 响应为 `success=true` 和 `data` 包装；`data.status` 只允许 `ready`，并返回可选 `access_node_id`、环境变量文本、安装命令和步骤说明。
- 请求、响应、审计摘要和安装说明不得回显完整 access-agent token、部署产物 token、真实目标地址或私有安装路径。公开示例只能使用 `example.test`、UUID 占位和 `<...>` 占位。

## 中转入口与线路

- `GET /api/admin/access-lines`：只读列出兼容订阅入口。新增入口应通过 `POST /api/admin/access-entries` 创建，并通过 `POST /api/admin/access-entries/{id}/exit-bindings` 创建入口出口绑定节点。
- `PUT /api/admin/access-nodes/{id}`、`DELETE /api/admin/access-nodes/{id}`、`POST /api/admin/access-nodes/batch-delete`：编辑、删除和批量删除中转节点。删除只清理控制台节点、从属入口和本机出口服务资源，不主动 SSH 清理目标服务器。
- `POST /api/admin/access-nodes/{id}/local-exit-lines`：批量创建中转服务器自建出口线路。请求字段为 `lines[]`，每条包括 `resource_name`、`endpoint_name`、`region_code`、`outbound_type`、`network_mode`、可选 `host`、`port`、`outbound_config`、`stream_config`、`probe_config`、`enabled`；`host` 省略时默认使用所属中转节点地址。旧单条直出接口已删除。
- `POST /api/admin/access-entries` / `POST /api/admin/access-entries/{id}/exit-bindings`：当前唯一公开主路径，用于维护用户入口并创建入口出口绑定节点。绑定节点选择 `exit_endpoint_id`，入口记录维护协议、客户端网络模式和监听端口；服务端不直接写入套餐授权。
- `GET /api/admin/exit-resources`：出口管理出口资源列表，返回后台运营字段。
- `PUT /api/admin/exit-resources/{id}`：修改出口管理出口资源名称、归属、地区、供应商或启用状态；修改后会标记引用该资源下 endpoint 的接入节点配置待同步。停用资源导致内部兼容集合无可用成员时，会禁用相关绑定节点并清理用户授权和内部映射。
- `GET /api/admin/exit-endpoints`：出口管理出口协议档列表，管理员后台返回真实 `host`、端口、`outbound_config`、`stream_config` 和 `probe_config`；订阅、普通用户接口、公开日志、截图、测试报告和提交说明不得回显这些敏感配置。
- `POST /api/admin/exit-endpoints`：创建出口管理出口协议档。管理员后台可提交真实上游地址、端口和协议配置；响应、审计和公开记录必须脱敏，不得扩散真实 IP、密钥、Token、密码或完整代理 URL。
- `PUT /api/admin/exit-endpoints/{id}`：编辑出口管理出口协议档。管理员后台可回显并修改真实配置；服务端会标记所有引用该 endpoint 的接入节点 dirty，下一轮 agent 同步使用新配置。若 endpoint 被停用导致内部兼容集合无可用成员，会同步禁用相关绑定节点并清理用户分配；公开输出仍不得泄露真实配置。
- `DELETE /api/admin/exit-endpoints/{exit_endpoint_id}`：删除出口管理出口协议档。服务端会清理该 endpoint 的运行兼容成员引用、分组成员、绑定该 endpoint 的中转入口 `access_lines`、`user_access_line_assignments` 和 `user_exit_assignments`，并标记相关 `access_nodes` dirty，使套餐入口授权、`/sub/{token}` 和中转节点配置保持一致。
- `GET /api/admin/exit-pools`：只读查看底层内部运行集合和成员健康，供排障使用。创建、替换成员、聚合新增出口和删除运行集合不再作为公开管理接口；入口出口绑定节点由后端使用对应出口线路的运行集合。
- 旧手动刷新类接口已下线；相关运行映射由资源、入口、分组、套餐、用户状态和 agent 同步结果变化自动收敛。

## 数据库备份

后台「数据库备份」页统一读写 `site_settings.setting_key='backup_config'`，管理四种能力（全量 pg_dump / 异地 rsync 同步 / WAL·PITR / 邮件发文件），各自独立开关、可组合可单选，调度自定义（间隔分钟 + cron）。全部端点用管理员 JWT，响应一律脱敏。详见 `开发方案.md` §11.4 与 `文档/运维手册/备份恢复.md`。

- `GET /api/admin/backup/config`：读取备份配置。异地机 SSH 密码、邮件附件口令明文存 `backup_config`（字段加密已下线），响应**只出脱敏布尔** `ssh_password_set`/`attach_passphrase_set`，绝不回显明文；中心机公钥只返回指纹。
- `PUT /api/admin/backup/config`：写入备份配置。密码/口令走写时保留（请求体留空或未变时保留原值，不覆盖成空）；写入不入日志或审计明文。
- `POST /api/admin/backup/test-and-provision`：测异地机 SSH 连通并自动装公钥。`ssh_host` 必须是 IP（域名尤其橙云 CF 无法直连 SSH，后端拒域名）；用页面填的 SSH 密码进异地机把公钥追加到 `authorized_keys` 去重、立即用密钥验证免密；成功置 `pubkey_installed=true`、记公钥指纹、SSH 密码按兜底口径落库；失败返回脱敏原因、不置位。
- `POST /api/admin/backup/run-now?mode=full|offsite|wal|email`：立即触发一次指定模式备份（排队给 worker 或直接执行）。
- `GET /api/admin/backup/state`：读取各模式最近状态与历史（`last_started_at`/`last_success_at`/`last_failed_at`/`error_summary`/`last_file_name` + `offsite_last_sync_at`/`wal_last_archive_ok`/`email_last_sent_at`），错误摘要脱敏。

## 监控中心（运营中心 + 健康检查合并）

监控中心把原「运营中心」与「健康检查」合并为统一页面（后台入口仍为 `/admin/access-operations`），在原有流量/健康能力之上新增平台资源指标与每节点运行指标。五个 tab：平台总览、节点运行指标、节点/线路流量、健康检查、运营告警。原健康检查全部能力（心跳、配置 desired/applied 同步、中转入口探针、组合探测、运行兼容集合健康、内核待升级提醒）与运营告警全部保留，仅入口与展示合并。

- `GET /api/admin/access-operations/platform-metrics`：监控中心平台总览。返回控制面 host（运行 api/worker/postgres 的服务器）CPU、内存、磁盘 指标与数据库存储量。响应结构 `{cpu:{pct_milli},memory:{used_bytes,total_bytes,used_pct_milli,free_pct_milli},disk:{used_bytes,total_bytes,used_pct_milli,free_pct_milli,host_mounted},database:{total_bytes,tables:[{name,bytes}]}}`；百分比统一为千分比（0-100000）。CPU/内存由 api 容器内 `/proc` 读取（容器内 `/proc` 默认即反映宿主，**无需挂载**）；磁盘由 `statvfs("/hostfs")` 读取，需 compose 把宿主根挂只读进容器（api 服务 `volumes: - /:/hostfs:ro`），未挂载时 `disk.host_mounted=false` 且磁盘字段置空、前端提示「未挂载 host 盘」；数据库存储量用 `pg_database_size(current_database())` + 主表 `pg_total_relation_size`，只读查询、不回显表内容。`/hostfs` 未挂载、`/proc` 读取失败或 `pg_database_size` 不可用时对应字段优雅降级，端点仍返回 200，向后兼容。鉴权与 `/api/admin/*` 一致（管理员 JWT）。
- `GET /api/admin/access-operations/summary`：监控中心健康检查和运营汇总。响应包含 `traffic_health`，其中 `windows.today/week/month/total` 展示真实流量和扣费流量，`node_items` 按中转节点展示今日、本周、本月、累计、小时峰值、小时低谷和本月按天图表，`exit_items` 按出口线路展示同口径数据，`group_items` 按分组展示同口径数据。统计读取保留期内 `usage_ledgers.traffic_source=access_line` 明细、过期明细生成的 `usage_daily_rollups` 和小时口径 `usage_hourly_rollups`，中转节点通过账本或汇总中的 `access_node_id` 归属，出口线路通过 `exit_endpoint_id` 归属，分组通过 `access_line_id -> access_lines.exit_endpoint_id -> line_group_exit_endpoints.line_group_id` 归属；不得用模拟数据、订阅数量或中心侧猜测填充。节点读模型新增 `access_nodes[].runtime_metrics` 键，回填该节点最近一次心跳 `node_metrics` 采样（CPU/内存/磁盘 使用率千分比 + 采样时间 + `status=fresh|stale`）；旧 agent 不上报或采样过期时回填 `null`，前端显示「未上报/已过期」，不得用 0 冒充。
- `GET /api/admin/access-operations/ledger-ranking?limit=10`：运营中心账本流量排行。服务端读取保留期内 `usage_ledgers` 明细和 `usage_daily_rollups` 历史日汇总，按内部 `access_line_id` 汇总 `delta_uplink`、`delta_downlink`、`real_bytes`、`billed_bytes` 和 `ledger_count`，默认按扣费流量降序返回 `items` 与全量 `totals`。
- `GET /api/admin/access-lines/{id}/metrics`：读取指定中转入口最近运行指标快照。响应包含 `ledger_summary`、兼容别名 `traffic_summary`、按小时聚合的 `ledger_windows` 和 `metrics`；`metrics` 项包含在线用户、连接数、`active_connection_count`/`active_connections`、独立客户端 IP 数和上下行速率。
- `GET /api/admin/access-lines/{id}/sessions`：读取指定中转入口最近会话。响应会话项包含 `client_ip_hash`、`active_connection_count`、兼容别名 `active_connections` 和 `status=online/offline/expired/unknown`；不得返回明文客户端 IP。

## 销售首页

- `GET /api/admin/sales-landing`：管理员读取销售首页配置。
- `PUT /api/admin/sales-landing`：管理员保存销售首页配置，配置存储在 `site_settings.sales_landing`，写入 `sales_landing.update` 审计日志。
- `GET /api/sales-landing`：公开读取销售首页配置，不需要登录；响应只包含展示文案，不得包含后台登录地址、Token、服务器信息或出口资源。
