# 订阅接口

## 下载

- `GET /sub/{token}`
- `POST /api/user/subscription/token/reset`
- `POST /api/admin/users/{id}/subscription-token/reset`

响应为 Clash/mihomo YAML，文件名来自后台订阅设置，不强制 `.yaml` 后缀。响应头包含 `profile-title`、`profile-update-interval`、`profile-web-page-url`、`Content-Disposition` 和 `subscription-userinfo`。节点名称使用入口出口绑定节点名，保持纯文本；普通 `select proxy-groups` 由套餐授权分组生成，组内成员是该分组下启用且可用的绑定节点代理项。一个入口绑定多个出口时，订阅按绑定节点输出多个代理项，允许这些代理项共用同一个 `server/port`，但必须使用不同节点名和绑定节点级用户凭据。订阅 YAML 不输出入口或分组 `icon` 字段。订阅内置一个 `dns` 段（`enable: true`、`enhanced-mode: fake-ip`、国内 `nameserver`/`proxy-server-nameserver`、国外 `fallback` 加 `fallback-filter` 按 `geoip=CN`/`geosite=[gfw]` 抗污染，并带本地/连通性探测域名的 `fake-ip-filter`），避免手机客户端（如 FLClash TUN）在无 DNS 配置时回落系统/运营商 DNS、被墙域名（Telegram 等）被 DNS 污染而无法访问；桌面客户端自带 DNS 兜底不受影响。该段为生成器内置默认（见 `crates/core/src/subscription/dns.rs`），数值均为公开 DNS，不含私密信息。

`/sub/{token}` 是系统唯一订阅方式，用户导入该链接即可，不需要 JWT。

订阅下载成功后，服务端会记录本次拉取来源 IP、IP 哈希、User-Agent 摘要和时间，用于管理员后台“用户管理 -> 设备管理”的 IP 观察列表。该记录只与节点使用 IP 做同用户去重展示，不新增第二套订阅方式，不影响节点选择、扣费、限速或套餐授权。

当前可进入用户订阅主链路的中转入口协议为 VLESS、Trojan、HY2、Shadowsocks 2022。VLESS 输出 VLESS 节点，Reality 安全层只允许 TCP、XHTTP 或 gRPC，不允许 UDP、XUDP 或 WS；Trojan 只输出 `password` 形态，不输出 VLESS 的 `uuid`、`flow` 或 Reality 字段；HY2 输出 `type: hysteria2`，使用用户当前 `access_credential` 作为 `password`，必须配置 TLS/SNI 和证书，不输出第三方 HY2 上游认证字段；Shadowsocks 用户入站必须使用 2022 系列方法，输出 `ss` 节点时必须在中转入口入站配置中提供 server password，并按 `server:user` 形态承载用户当前入站凭据。agent 下发 Xray 服务端入站时使用 `settings.clients` 保存用户密码和统计 email。旧 `aes-*-gcm` Shadowsocks 只允许作为内部或出口协议，不得进入用户订阅、用户级路由或计费主链路。HTTP、SOCKS 和 VMess 入站当前无法稳定绑定 `xray_email` 统计身份，不能渲染成订阅节点，也不能回退为 VLESS。

订阅只读取套餐授权分组下的可用入口出口绑定节点，并按“套餐授权分组 -> 分组内绑定节点 -> 绑定节点对应中转入口”生成代理节点。客户端普通分组对应授权分组；入口禁用、订阅额度耗尽、中转节点不可用、无可用出口或套餐授权变化时，下一次下载会剔除不可用绑定节点；无可用入口时返回明确业务错误，不能用 500 掩盖配置问题。

线路探测异常默认不作为订阅可见性剔除条件：中转入口或出口组合被探测为 `offline/unhealthy` 时，订阅仍继续显示对应节点，由运营中心展示状态。只有管理员在后台订阅设置开启 `block_unhealthy_lines` 时，`/sub/{token}` 才会屏蔽探测异常线路。

订阅规则分两层：分组绑定的规则库先输出，后台规则设置里的通用规则后输出。规则库里的 `PROXY` 或未指定动作的规则在生成订阅时目标指向当前绑定分组；`DIRECT`、`REJECT`、`REJECT-DROP` 或 `PASS` 保持原动作。同一规则库可以绑定到多个分组，订阅会按每个分组各自生成目标不同的规则。通用规则中的 `PROXY` 和最终 `MATCH` 指向套餐默认出口分组。通用规则为空时采用“中国地区直连、海外 AI 强制代理、其他流量走代理”：ChatGPT/OpenAI、Claude/Anthropic、Grok/xAI、Gemini/Google AI、Perplexity、Poe、Cursor、Codeium、Windsurf 等国外 AI 域名优先走代理；本机、私有网段、`.cn`、常见国内域名、`GEOSITE,CN` 和 `GEOIP,CN` 走 `DIRECT`。规则库和通用规则都未命中时，生成器自动追加 `MATCH,套餐默认出口分组`，默认走代理。

后台 `/admin/rule-settings` 提供规则可视化编辑器：通用规则可选择代理、直连、拒绝或拒绝丢弃；规则库可新增、编辑、停用和删除，代理动作显示为“走绑定分组”，并隐藏 MATCH 兜底项。分组编辑页选择要绑定的规则库并保存顺序。前端把规则类型、匹配内容、动作和 `no-resolve` 组合成 Clash/mihomo 规则字符串后提交；高级文本模式仍可直接编辑字符串数组。规则库接口为 `/api/admin/subscription-rule-sets`，分组绑定随 `/api/admin/line-groups` 的 `rule_set_bindings` 字段提交。

## 防泄露

订阅不得包含 `exit_endpoints`、第三方出口 host、账号密码、access-agent token、Reality 私钥或代理 URL。

订阅 Token 运行校验使用 `subscription_tokens.token_hash`，同时检查 `revoked_at IS NULL`、Token 未过期、用户未禁用、订阅 active 且订阅未过期。用户或管理员重置订阅链接后，旧 Token 必须立即失效，同时轮换节点入站凭据和统计归属 key，并标记中转节点配置待同步，避免旧客户端继续使用旧 YAML 产生流量。

公开文档、日报、测试报告和日志只允许记录是否存在订阅下载地址、HTTP 状态和节点数量，不得记录完整订阅链接、订阅 Token、客户端代理 URL、真实出口 IP 或响应全文。
