# 流量上报

本文档适用于中转节点 `access-agent` 上报的中转入口流量、运行指标和在线会话。内部仍使用 `access_line_id` 做账本归属。

## 数据来源

流量快照来自接入节点本机 Xray Stats API。中心按 `access_line_id + xray_user_key` 的累计计数差值入账，不能直接累加累计值。

## 运行数据

`metrics` 上报中转入口速率、在线用户和连接数；`sessions` 从 Xray access log 增量解析用户、客户端 IP 哈希和连接活跃时间后上报在线会话摘要；`probes` 上报中转入口和 `access_node -> exit_endpoint` 组合探测状态。

中心不可达或拒绝流量报告时，access-agent 会把本轮待上报快照写入本机 `XRAYC_TRAFFIC_BACKLOG_PATH`，下一轮与新快照合并补发。补发队列只保存节点本机运行必需数据，不应复制到公开日志或测试报告。

## 验证方式

基础验证运行 `scripts/real-smoke.sh`。真实公网验收运行 `scripts/real-access-pool-e2e.sh` 或第三方出口专用 E2E 脚本。
