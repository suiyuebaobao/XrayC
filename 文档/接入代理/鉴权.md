# 接入代理鉴权

本文档的“接入代理”指部署在接入节点上的 `access-agent`，不代表独立控制组件。

## Token 保存

中心只保存 access-agent token 的 SHA-256 哈希。目标服务器 token 只写入 root `0600` 的 `/etc/xrayc/access-agent.env`。

## 校验规则

服务端按 `access_node_id + bearer token` 校验请求。`access_node_id` 或兼容字段 `node_id` 必须是明确接入节点 UUID；无 token、错误 token、节点 ID 缺失、格式错误或节点不存在时返回拒绝结果，不能用任意默认节点兜底。

## 轮换与撤销

轮换 token 时需要后台更新节点凭据并重新部署或更新目标服务器 env。撤销节点时应禁用节点、标记配置 dirty，并停止对应目标服务器服务。
