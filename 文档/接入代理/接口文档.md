# 接入代理接口文档

本文档描述部署在接入节点上的 `access-agent`。当前文档语义统一为接入代理，不再引入其他 agent 命名或独立控制组件。

## 通信方式

access-agent 主动回连中心控制面，所有 `/api/agent/access/*` 请求必须携带 `Authorization: Bearer <agent_token>`，并在请求体携带明确 `access_node_id` 或兼容字段 `node_id`。中心只按该节点校验 token 和生成配置，不允许回退到默认节点。

## 接口清单

- `POST /api/agent/access/heartbeat`：心跳、配置拉取和探测任务拉取。
- `POST /api/agent/access/config-result`：配置应用结果。
- `POST /api/agent/access/traffic`：用户累计流量快照。
- `POST /api/agent/access/metrics`：中转入口运行指标。
- `POST /api/agent/access/sessions`：在线会话摘要。
- `POST /api/agent/access/probes`：中转入口和出口组合探测结果；HY2/Hysteria2 入口与出口 endpoint 使用 UDP 可达性探测，TCP 只用于 TCP 类协议；本机 UDP 端口明确拒绝时必须上报 `unhealthy`，不能把只发送 UDP 探测包视为成功。

## 流量归属

access-agent 通过中转节点本机 Xray Stats API 读取用户累计计数，并只接受 `xrayc-line-<access_line_id>--<xray_user_key>` 或历史兼容线路前缀。第三方上游 SOCKS/HTTP 等出口认证用户可能也会出现在 Xray `user>>>` 统计里，但这类无线路归属的计数不得进入 `/api/agent/access/traffic`、运行指标、用户级流量日志或中心账本。

## 脱敏要求

请求日志不得输出完整 token、第三方上游账号密码、Reality 私钥或用户明文 IP 批量列表。

`sessions` 上报 `client_ip` 和 `client_ip_hash`，中心只允许在管理员后台指定用户的流量日志中展示明文客户端 IP。普通用户接口、订阅、公开日志、截图、日报和测试报告不得回显明文 IP；`client_ip_hash` 由中心按 `client_ip` 重新计算，避免 agent 上报值和明文 IP 不一致。

## 在线会话上报

`POST /api/agent/access/sessions` 请求体字段：

- `access_node_id`：中转节点 ID。
- `sessions[].access_line_id`：中转入口 ID。
- `sessions[].xray_user_key`：用户稳定统计 key。
- `sessions[].client_ip`：从中转节点 Xray access log 解析出的客户端 IP。
- `sessions[].client_ip_hash`：兼容旧 agent 的 IP 哈希；新版中心会按 `client_ip` 重新计算。
- `sessions[].active_connection_count`：当前活跃连接数。
- `sessions[].started_at_unix`、`sessions[].last_seen_at_unix`：会话起始和最近活跃时间。
