# 2026-06-12 日报

## 入口协议与官方文档口径

- 规则文件新增硬约束：协议能力、客户端订阅格式、runtime core、部署工具、数据库和第三方组件行为不确定时，必须先查官方文档或上游主仓库文档，再更新代码、测试和方案。
- 入口管理按 runtime core 筛选协议：Xray 显示 VLESS、Trojan、HY2、Shadowsocks；sing-box 额外显示 AnyTLS。AnyTLS 只允许 sing-box + TCP/TLS，不写成 VLESS 的 transport/security。
- VLESS Reality 用户入口按 Xray transport/security 官方口径限制为 TCP、XHTTP、gRPC，不开放 UDP、XUDP 或 WS；非 Reality VLESS 才开放 UDP、XUDP、WS 等网络模式。

## 入口多网络模式

- 入口创建弹窗的网络模式改为多选，按协议与 VLESS security 过滤可选项。
- 选择多个网络模式时，前端按选择顺序调用现有单入口 API 创建多条单模式入口，监听端口从起始端口递增；例如起始 443 同时选择 TCP 和 WS，会创建 443/TCP 与 444/WS 两条入口。
- Playwright smoke 覆盖 Cloudflare TLS WebSocket 入口创建：同一次提交保留 TCP，并额外创建 WS 入口，断言 WS 字段、CDN 字段和端口递增。

## AnyTLS 测试补强

- DB、订阅、xray-config 和真实入口矩阵脚本补充 AnyTLS 入口约束与 sing-box 客户端配置生成。
- 公开方案和接口文档明确：sing-box AnyTLS 当前只能声明配置、订阅和连通性闭环；在用户级统计接入前，不能宣称与 Xray Stats API 等价的计费、会话和超额剔除闭环。

## 前端构建

- Vite 构建增加稳定 vendor chunk 拆分：Vue/Pinia/Router、Element Plus、VueUse 和其他第三方依赖分包，业务入口 chunk 从原先超过 1MB 收敛到约 74KB。
