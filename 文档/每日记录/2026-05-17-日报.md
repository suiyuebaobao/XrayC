- 新增用户出口运行分配基础闭环：订阅和用户订阅读模型会同步 `user_exit_assignments`，已有健康出口保持不变，当前内部运行集合成员 `offline` 后自动切换到同池健康出口；内部运行集合列表的 `active_assignments` 改为真实分配数量。

- 新增 heartbeat `AccessConfig` 下发闭环：中心按 `user_exit_assignments` 生成中转入口、授权用户和用户级 `routing_rules`；`config_status.required=false` 时返回 `config=null`。
- 扩展 heartbeat 出口下发范围：当日实现无认证/带认证 SOCKS、无认证/带认证 HTTP、VLESS、Trojan、Shadowsocks、Hysteria/HY2 上游；后续公开主流程已收口为第三方或普通自建上游出口。
- 新增 `202605170004_remove_rate_limit.sql`，移除已下线的用户级限速表和接入节点端口池字段；订阅只输出 `access_lines.listen_host/listen_port`。
- access-agent 增加 `config_status.required=true` 且 `config=null` 的兜底处理：写入空入口 + blackhole outbound 配置，避免控制面无可用中转入口时旧 Xray 用户继续保留。
- agent API 收紧节点身份契约：PostgreSQL 模式下 `access_node_id/node_id` 必须是 UUID 且必须存在于请求体中，服务端按该节点绑定 token 校验，不再回退到第一台节点；`config-result` 不再回显请求体。
- 前端登录后按角色跳转：普通用户进入订阅页，管理员进入概览；普通用户隐藏后台菜单并禁止进入管理员页面。
- 新增 `/api/agent/access/config-result` 配置结果落库规则：成功但未回传 hash 不清理 dirty，只有成功且 hash 匹配 `desired_config_hash` 才更新 `applied_config_hash` 并清理 dirty；失败会保留 dirty 并记录脱敏错误摘要。
- access-agent 流量上报从空快照改为真实 Xray Stats API 采集：通过 `xray api statsquery` 读取 `user>>>...>>>traffic` 累计计数，解析中转入口作用域用户 email，并按快照上报中心。
- 新增运行数据上报闭环：`POST /api/agent/access/metrics` 写入 `access_line_metric_snapshots`，`POST /api/agent/access/sessions` 写入 `access_user_sessions`，`POST /api/agent/access/probes` 写入 `access_line_probes` 和 `access_exit_probes`；PostgreSQL 模式会校验中转入口归属当前接入节点。
