## 1. 节点多域名模型(迁移 `202606230001`)

- 节点从单 `cert_domain` + 单 `cf_domain` 升级为**多个直连域名 + 多个 CF 域名**:新建 `node_domains` 表(`access_node_id` + `domain` + `kind∈{direct,cf}` + `cf_cert_mode` + `acme_email` + `is_primary` + `cert_status`,同节点 `domain` 唯一)。一节点多行,按 kind 分两组。
- 旧单字段向后兼容:迁移把 `cert_domain` 搬一行 `kind=direct,is_primary=true`、`cf_domain` 搬一行 `kind=cf,is_primary=true`(`ON CONFLICT DO NOTHING`),旧单字段作为各组**主域名**快捷指针,写入以 `node_domains` 为准。
- `cf_enabled` 由"存在 `kind='cf'` 的域名"派生(`node_has_domain_kind`),不再依赖单 `cf_domain` 字段。
- 删除被入口/本机出口引用的 `node_domain` 行被拒(先改引用再删),避免悬挂引用。

## 2. 入口 / 本机出口选域名 + 护栏按"选中域名 kind"

- `access_entries` 与 `exit_endpoints`(本机出口 `ownership=self_hosted`)各加 `node_domain_id`(免证书入口/出口留空)。
- **协议护栏按选中域名的 kind 判定**(不再按节点单域名):
  - 选 CF 域名(`kind=cf`)→ 只放 (VLESS|Trojan) + (WS/gRPC/XHTTP) + TLS。
  - 选直连域名(`kind=direct`)→ 放 Trojan/HY2/VLESS-TLS。
  - 不选域名(留空)→ Reality/SS/SOCKS5/HTTP(免证书直连)。
- 入口证书锚定改为按选中 `node_domain` 的 domain/kind/cf_cert_mode(非节点主域名)。
- 订阅按入口选中域名输出 SNI/连接地址;未选用节点主域名/IP(行为同今天)。这构成**防封轮换**:节点囤多个已签好证书的备用域名,被墙时把入口下拉切到另一个域名,订阅内容更新、客户端刷新即迁过去,目标域名证书早就绪、切换即时。

## 3. 证书遍历签发

- agent 从心跳下发的 `node_domains` 列表**遍历逐个签证书**:`kind=direct`→HTTP-01(`--standalone`)、`kind=cf`→DNS-01(`certbot-dns-cloudflare` + CF Token)。
- 各域名 `x509 -checkend` 仍有效即跳过(沿用上一特性防 LE 限流口径);CF 多域名各自从 env 注入 token(同账号复用),token 不落控制面库。

## 4. 一键安装仅 IP 部署(正确性修复)

- 一键安装的 **SSH 目标必须是 IP**:后端 `resolve_one_click_agent_install_request` 校验 `ssh_host.parse::<IpAddr>()`,传域名(尤其橙云 CF 代理无法直连 SSH)直接 Err"SSH 地址必须是 IP"。
- **SSH IP 是独立字段,与客户连接地址(域名直连/CF直连/IP直连)完全无关、不联动**:前端彻底移除从 `public_host`/任何客户连接地址自动带出 SSH Host 的 watcher,自动填值来源改为 `ip_direct_address`,提交前前端也校验 IP。`public_host` 等客户地址保持原样(客户端连的,与 SSH 无关)。

## 5. 本机出口协议扩展 + 全对象可编辑

## 9. 遗留 / 风险

- 灰云 HTTP-01 单域名重验仍受上周 LE 限流窗口影响(逻辑与多域名遍历同,已多机验过两张直连证书);限流解除后可再补真机重签。

- 多 CF 域名跨不同 CF 账号时需各传各自 token(同账号可复用一个 token);token 始终仅安装/续期期注入,不落控制面库。

## 10. 真机多用户测试暴露的 3 个产品缺口修复(分支 `fix/multiuser-findings`,已合并 main)

no-mock 多用户真机测试(4 台服务器:3 转发 + 1 客户端,3 连接模式灰云/橙云/IP,3 用户真流量)暴露并修复 3 个缺口,全程 TDD 真 PG:

- **Fix1 本机出口 host 默认值**:host 留空时默认从 `public_host` 改为 `LOCAL_EXIT_DEFAULT_HOST = "127.0.0.1"`(`routing_local_exits.rs`)。根因:橙云节点 `public_host` 是橙云域名(经 CF 代理),本机出口被同节点中转回拨时连不通;改默认 loopback 后,中转与本机出口同主机,loopback 永远可达、与节点类型无关。渲染侧本机出口 inbound 绑 `0.0.0.0`,127.0.0.1 可达。
