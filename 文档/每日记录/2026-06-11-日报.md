# 2026-06-11 日报

## 更新

- 新增中转节点 SSL 证书状态闭环：access-agent 心跳上报证书域名、状态、有效期、剩余天数和脱敏错误摘要，管理平台在中转节点卡片展示。
- 新增单节点 SSL 续期任务：管理员在中转节点卡片点击“续期 SSL”，中心写入该节点任务，agent 下一次心跳领取后使用本机 certbot 非强制续期，成功后 reload Xray 并回报结果。
- Agent 安装脚本改为只有证书域名和 ACME 邮箱同时存在时才自动申请证书；域名会写入 agent 环境用于后续状态上报，任一缺失时跳过证书申请并提示原因。
- 文档同步补充 SSL 状态上报、单节点续期、安全脱敏和部署脚本域名/邮箱规则，避免继续残留跨节点证书操作或后台登录目标服务器安装的语义。

## 验证

- 已通过 access-agent 心跳 JSON 和 TLS 目标收集单测。
- 已通过部署脚本静态契约检查。
- 已通过前端生产构建。
- PostgreSQL 相关 focused 测试在当前环境缺少 `DATABASE_URL` 时按既有逻辑跳过真实数据库连接；最终发布前仍需跑 `make check-postgres-integration`。
