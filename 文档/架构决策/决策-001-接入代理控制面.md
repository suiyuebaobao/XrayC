# 决策-001-接入代理控制面

## 背景

V2 需要把用户鉴权、流量统计、中转入口控制和内部出口映射集中到中转接入节点。

## 候选方案

- 接入节点部署 access-agent 主动回连中心。

## 已否决/非采用方案

- 中心直连所有出口并控制用户：已否决。该方案要求中心持有并主动访问各类出口或节点入口，扩大网络暴露面，也不符合当前“中心只强控制自建接入节点、出口弱管理”的边界。

## 最终选择

采用 access-agent 主动回连中心。中心只暴露 API，节点通过 bearer token 鉴权拉取配置、上报运行态和流量。

## 影响

该方案避免中心主动访问节点内网，便于控制面迁移；要求 agent 心跳、配置回滚和运行态上报必须可靠。
