# 鉴权与交互

## 鉴权模型

浏览器使用 JWT Access Token 调用 API，Refresh Token 使用 HttpOnly Cookie。前端不得读取、打印或持久化 Refresh Token。

## 路由守卫

未登录用户访问控制台时跳转 `/login`。普通用户访问 `/admin/*` 时回到 `/subscription`；管理员访问用户页时进入管理概览。

## 验证码与错误提示

注册、用户登录和管理员登录根据 `/api/auth/security` 返回的策略决定是否展示验证码。登录失败锁定、邀请码缺失和邮箱域名限制必须给出明确提示。

## 防泄露

前端不得展示第三方出口 host、账号、密码、代理 URL、access-agent token 或 Reality 私钥。订阅页只展示中转入口和 `/sub/{token}`。

管理员用户管理里的设备管理抽屉只展示该用户的 IP 观察结果、来源、最近入口和最近状态，不展示订阅 Token、第三方出口配置或真实代理 URL，也不提供影响订阅凭据的操作。
