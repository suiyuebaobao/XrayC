# 页面清单

## 用户侧

- `/`：公网销售首页，面向 VPN 节点、流量套餐和节点服务转化，不要求登录。
- `/platform`：平台能力介绍页，保留接入控制、套餐订阅、运营观测和认证安全说明。
- `/login`：邮箱或管理员账号登录。
- `/register`：邮箱注册、邀请码和验证码入口。
- `/dashboard`：用户首页，展示当前套餐、用量、套餐授权分组内绑定节点对应的可连接中转入口和快速入口。
- `/plans`：用户套餐页，读取公共套餐列表；当前支付暂停时只展示套餐与暂停状态，不创建订单。
- `/subscription`：套餐、用量、订阅链接和套餐授权分组内绑定节点对应的可连接中转入口。
- `/orders`：用户订单。
- `/redeem`：兑换码提交。
- `/invite-codes`：用户自助邀请码。

## 管理侧

- `/overview`：管理概览。
- `/admin/tutorial`：管理员后台使用教程。用静态内容说明“出口管理 -> 入口管理 -> 入口出口绑定节点 -> 分组 -> 套餐授权 -> 用户订阅 -> 日常运维”的标准操作路径，不发起 API 请求，不展示私有服务器、订阅 Token、代理凭据或真实出口地址。
- `/admin/transit-nodes`：中转节点主页面。展示中转节点、中转入口、一键安装 Agent、Agent 手动安装说明、编辑、删除、批量删除和“本机出口服务”；一键安装临时收集 SSH 信息并只在本次请求内使用，安装成功后自动创建中转节点，手动安装说明继续返回服务器本地执行命令。本机出口服务通过节点详情专用动作批量添加该服务器自建出口线路，默认展示 VLESS、HY2、Shadowsocks、Trojan 四类协议行，支持选择网络模式、监听端口和协议必要字段，前端自动生成连接配置；服务地址默认读取所属中转节点地址，管理员只在默认值不符合实际监听地址时覆盖。保存后只进入统一出口管理，不自动创建入口，也不会加入分组。旧 `/admin/access-routing` 保留为兼容别名。
- `/admin/line-pool`：出口管理主页面。统一新增外部供应商线路、普通自建线路和本机出口服务登记后的线路，支持粘贴 Clash/mihomo YAML、代理 URI、Xray outbound JSON 和半结构化文本自动识别预填；展示真实 endpoint，支持搜索、编辑、探测和删除。管理员后台可见真实地址和协议配置，但订阅、普通用户页面、公开日志、截图和测试报告不得泄露真实 IP、密钥、Token、密码或完整代理 URL。
- `/admin/access-entries`：入口管理主页面。创建和编辑中转节点用户入口时按官方协议能力显示入口协议和网络模式，所有入口都由 Xray 处理：入口协议可选 VLESS、Trojan、HY2、Shadowsocks；VLESS Reality 只显示 TCP、XHTTP、gRPC。创建入口多选网络模式时会展开成多条单模式入口，监听端口从起始端口递增。绑定线路是入口行操作里的动作，不做单独菜单。
- `/admin/line-groups`：分组主页面。分组只有一层，直接选择入口出口绑定节点，例如 AI 分组、游戏分组、GPT 分组、视频分组；同一个入口绑定多个出口时会出现多个可选绑定节点；不维护多级结构或组合分摊策略。
- `/admin/rule-settings`：规则设置页。集中维护订阅通用规则和可复用规则库；分组在编辑页绑定规则库，通用规则未命中时默认走套餐默认出口分组，规则库里的“走绑定分组”在订阅生成时指向当前分组，直连和拒绝保持原动作。
- `/admin/access-operations`：运营中心和健康检查页，展示 access-agent 上报的真实在线、连接数、探测和流量健康数据；运营策略里可维护组合探测策略、详细流量日志保留天数、自动数据库备份开关、备份间隔和备份保留天数；同时提供运行态、账本排行、queued 探测队列诊断，展示值必须来自真实 API 或明确显示未上报。
- `/admin/plans`：套餐 CRUD 与分组授权；套餐直接授权分组，不维护层级结构、运行组合或出口管理成员，用户订阅按授权分组内绑定节点对应的可连接中转入口展示，节点数量以绑定节点为准。
- `/admin/sales-landing`：销售首页配置，维护标题、导航、CTA、卖点、套餐卡片、场景、FAQ 和页脚链接。
- `/admin/users`：用户 CRUD、订阅详情、订阅链接重置、用户级流量日志快捷入口和设备管理 IP 观察抽屉；设备管理合并订阅拉取来源和节点使用来源，同一明文 IP 只展示一条。新增用户可填写邮箱、密码、启用状态、管理员标识和套餐，编辑可维护邮箱、启用状态、管理员标识和当前套餐，删除用户只删除该用户数据不删除线路。
- `/admin/traffic-logs`：管理员后台“用户流量日志”，按用户查看保留期内的访问 IP、入口、出口端点、真实流量和扣费流量；超过保留期的明细只保留日/小时汇总，不再展示单条日志。
- `/admin/orders`、`/admin/redeem-codes`、`/admin/invite-codes`、`/admin/auth-security`、`/admin/audit-logs`：订单、兑换码、邀请码、认证安全和审计日志。
- `/admin/field-encryption`、`/admin/subscription-settings`：字段加密轮换状态和订阅 YAML 基础设置，属于高级运维入口。

## 验收路径

`frontend/e2e/smoke.spec.ts` 至少覆盖公共首页、平台页、普通用户首页/套餐/订阅路径和管理员教程页、中转节点/出口管理搜索编辑探测删除/分组/套餐/销售首页配置路径。新增关键写操作时应增加对应 Playwright 用例，出口管理删除后必须验证分组、入口授权、订阅输出和中转节点待同步状态保持一致。
