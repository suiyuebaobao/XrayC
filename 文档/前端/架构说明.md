# 前端架构说明

## 技术栈与边界

前端使用 Vue 3、Vite、TypeScript、Element Plus 和 Pinia。页面只消费中心 API，不直连接入节点、Xray 或第三方出口。

## 目录结构

- `frontend/src/router/`：路由与权限守卫。
- `frontend/src/services/api.ts`：统一 API 客户端和响应归一化。
- `frontend/src/stores/`：登录态、用户信息和全局状态。
- `frontend/src/views/`：用户侧与管理后台页面。

## 交互约定

后台页面必须使用真实 API，不允许保留“后端接口待接入”作为已完成状态。产品主路径必须简化为“出口管理、入口管理、分组、规则库、套餐和中转节点”：出口管理保存所有来源的出口线路，入口管理创建中转入口并绑定线路形成订阅节点，分组只有一层并直接归类入口出口绑定节点，规则设置页集中维护通用规则和可复用规则库，分组只绑定规则库，套餐直接授权分组并设置倍率。入口管理创建和编辑入口时按官方协议能力筛选入口协议和网络模式，所有入口都由 Xray 处理：入口协议可选 VLESS、Trojan、HY2、Shadowsocks；VLESS Reality 只允许 TCP、XHTTP、gRPC；创建入口多选网络模式时按选择顺序展开为多条单模式入口，监听端口从起始端口递增。入口的“绑定线路”放在入口行操作中，不做独立菜单。中转节点页只维护节点、Agent 安装说明、本机出口服务、SSL 和运行态，不再直接创建订阅节点。订阅设置页只维护 YAML 基础字段、线路过滤和自动测速，不再自定义普通代理分组；规则编辑器优先使用可视化表单，保留高级文本模式，通用规则最终提交 `default_rules` 字符串数组，规则库最终提交到 `/api/admin/subscription-rule-sets`，分组绑定最终提交 `rule_set_bindings`。管理员“使用教程”页是静态说明页，只解释标准操作路径，不读取或展示私有运行数据。涉及订阅、运行监控、分组、规则和中转节点的页面变更必须补 Playwright smoke 或真实接口 smoke。
