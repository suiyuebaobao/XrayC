# 常见问题

## 订阅可下载但节点不可用

检查 `docker compose ps`、`/health`、接入节点心跳、Xray 配置应用结果和绑定节点的出口健康状态。订阅只说明用户拿到了中转入口，不代表该入口背后的出口一定健康；继续核对 `config_status.required`、`applied_config_hash`、当前入口绑定节点的出口 endpoint 和 `access_node -> exit_endpoint` 组合探测状态。

如果刚重装或迁移接入节点，确认 access-agent 首次心跳没有本地 `applied_config_version` 时中心重新下发了完整 `AccessConfig`。配置应用成功后必须调用 `/api/agent/access/config-result`，且 hash 匹配后 dirty 才会清理。

## 运营中心无运行数据

确认 access-agent 已上报 `metrics`、`sessions` 和 `probes`，并检查节点 token、系统时间和 Xray Stats API 配置。`runtime_metric_status=no_data/unknown` 时页面必须显示未知或未上报，不得用 0 冒充真实在线、连接数或速率。

若只有 queued 探测长期存在，检查 Worker 是否在按策略排队、access-agent 心跳是否领取 `probe_tasks`、以及 `/api/agent/access/probes` 是否回报非 queued 结果。queued 任务本身不参与失败/恢复阈值；若租约反复过期并达到 `max_probe_task_delivery_count`，Worker 会把任务转成 `timeout` 并按失败结果推进组合状态。只有 agent 回报或 Worker 超时终态产生的 `healthy/online/success`、`timeout/error/offline/unhealthy` 才会改变组合状态。

## 订阅泄露风险

运行 `scripts/real-smoke.sh` 和对应 `scripts/real-access-*.sh`，确认订阅中没有第三方 host、账号密码、access-agent token 或代理 URL。

## 支付接口返回暂停

当前默认 `XRAYC_PAYMENT_ENABLED=false`。用户创建订单和支付回调写接口返回支付暂停是预期行为；不要为了恢复订单创建而写入演示收款地址。正式启用支付前必须补齐回调密钥、收款地址、最小确认数、对账方案和公网回调 E2E。

## 字段加密轮换失败

先确认 API 和 Worker 使用同一个字段加密 keyring provider。dry-run 失败时不要删除 `field_encryption_rotation_jobs`，应先恢复包含旧 `kid` 的 keyring，再重新执行 dry-run。正式轮换只记录任务 ID、状态和计数，不得把 key material、密文或明文复制进工单。
