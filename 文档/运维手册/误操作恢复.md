# 误操作恢复

## 适用范围

本文用于运营误禁用出口管理 endpoint、入口出口绑定节点、中转入口或普通套餐后的恢复演练，也用于隔离数据中的错误出口映射恢复验证。恢复动作必须只针对确认过的临时数据或明确的业务对象；生产恢复前先记录对象 ID、影响用户范围、当前订阅可见入口、账本基线、审计记录和接入节点 dirty 状态。

生产恢复优先使用出口管理资源启停、中转入口启停、入口出口绑定节点恢复、套餐分组授权恢复和接入节点 dirty 同步，不直接删除真实出口资源、中转入口、套餐、订阅或账本。任何真实对象恢复都必须先确认订阅仍未泄露出口地址和凭据，再让 access-agent 重新同步配置。

## 真实 UAT

执行真实误操作恢复 UAT：

```bash
XRAYC_REAL_RELEASE_ENV_FILE=/absolute/private/env/path \
RUN_OPS_MISTAKE_RECOVERY_UAT=1 \
bash scripts/ops-mistake-recovery-uat.sh
```

脚本只创建临时用户、临时套餐、临时出口 endpoint、临时中转节点和临时中转入口，并在隔离数据中准备必要的内部兼容映射，不停止服务、不重启 access-agent、不触碰 SSH。需要管理员 JWT，或通过私有 env 提供管理员登录账号和密码换取 JWT；脚本不会输出凭据。默认会清理临时数据；如需保留排查，设置 `OPS_MISTAKE_RECOVERY_UAT_KEEP_DATA=1`，并在排查后按脚本中的临时 run 标记清理。

大数据恢复演练只能使用隔离 PostgreSQL：

```bash
XRAYC_REAL_RELEASE_ENV_FILE=/absolute/private/env/path \
RUN_OPS_MISTAKE_RECOVERY_LARGE_UAT=1 \
OPS_MISTAKE_RECOVERY_LARGE_DATABASE_URL=postgres://example.invalid/xrayc_loadtest \
bash scripts/ops-mistake-recovery-large-uat.sh
```

该脚本会复用运行态 large 压测种子，在隔离库中验证线路 endpoint 禁用、受影响分配清理、接入节点 dirty 标记、审计脱敏、恢复和关键查询延迟预算。禁止把真实发布 `DATABASE_URL` 作为大数据演练库。

恢复动作优先走当前真实 admin API：出口管理资源、中转入口、分组绑定节点和套餐分组授权恢复使用现有接口，套餐删除迁移使用 `DELETE /api/admin/plans/{id}`。内部兼容成员禁用、错误出口分配和恢复只允许在隔离 UAT 临时数据中用 SQL 演练；生产恢复不得调用已下线的手工成员替换或手工重平衡接口。

通过标准：

- 通过隔离 SQL 禁用临时内部兼容成员或禁用临时中转入口后，订阅不再暴露不可用入口，相关临时分配被清理，接入节点写入对应 dirty reason。
- 通过隔离 SQL 恢复临时内部兼容成员或恢复临时中转入口后，重新下载订阅可生成可用分配，订阅仍只暴露中转入口。
- 通过 admin API 删除普通临时套餐后，临时订阅迁移到默认套餐，旧授权和旧分配被清理，接入节点标记 dirty。
- 错误出口分配后，通过隔离 SQL 恢复为规则选择的可用出口；下一次订阅生成保持可用，dirty reason 为本次 UAT 的恢复标记。
- 临时账本存在且可按用户和中转入口追溯；审计摘要存在且不包含订阅 token、数据库 URL、真实 IP、上游地址或代理凭据。

## 人工恢复顺序

1. 冻结继续操作，记录相关套餐、分组、入口出口绑定节点、中转入口、出口 endpoint、用户和接入节点 ID。
2. 查询审计日志，确认误操作动作、操作者、时间和脱敏摘要。
3. 恢复分组绑定节点、中转入口、套餐分组授权或出口管理资源状态；出口维护优先通过资源启停和探测状态收敛，不直接删除。
4. 清理受影响用户、中转入口、套餐分组授权范围内的临时错误分配，等待系统按当前规则重算。
5. 标记相关接入节点 dirty，等待 access-agent 心跳下发配置并回报 hash 匹配的 `config-result`。
6. 下载受影响测试用户订阅，确认只暴露中转入口；随后用真实客户端私有代理验证出站和账本增长。
7. 把恢复结果、影响范围、验证命令模板和遗留风险写入当日日报，不记录真实地址、Token、订阅链接或代理 URL。

## 脱敏要求

脚本和人工记录只能输出阶段名、计数、HTTP 成败和脱敏失败原因。禁止打印 `DATABASE_URL`、订阅 token、JWT、Cookie、真实服务器 IP、SSH 账号密码、第三方上游 host、代理 URL、UUID 凭据或出口协议完整配置。
